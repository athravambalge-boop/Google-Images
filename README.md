# Atharva Ambalge image site

A small, image-first personal website for GitHub Pages.

## Add your images

Put your own photos in `images/` using these names:

`atharva-01.jpg` through `atharva-06.jpg`

To show more or fewer photos, edit the repeated `figure` blocks in `index.html`. Keep each `alt` description accurate to the image.

## Publish with GitHub Pages

1. Create a new **public** repository on GitHub, for example `atharva-ambalge`.
2. Upload all files from this folder, including the `images` folder.
3. In the repository, open **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Your site will be available at `https://athravambalge-boop.github.io/Google-Images/`.
6. Open that URL in a private browser window and check every image before submitting it to Google.

## Connect Google Search Console

1. Open [Google Search Console](https://search.google.com/search-console) and choose **URL prefix**.
2. Enter the exact GitHub Pages URL, including the repository path.
3. Choose **HTML tag** verification and copy the provided `<meta>` tag into the `<head>` of `index.html`.
4. Push the updated file to GitHub. Return to Search Console and click **Verify**.
5. Submit the sitemap URL: `https://athravambalge-boop.github.io/Google-Images/sitemap.xml`.
6. Use **URL inspection**, enter your homepage URL, and choose **Request indexing**.

The site URL is already configured for `athravambalge-boop/Google-Images` in the structured data, sitemap, and robots file.

Search indexing can take days or weeks and Google decides which pages appear for a name. Use the same spelling, `Atharva Ambalge`, consistently and link to this page from any genuine social or professional profiles you control.
